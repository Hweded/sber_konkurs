# СберИндекс: прогноз расходов и структурные изменения

Prophet, глобальный CatBoost и zero-shot Chronos-Bolt; причинная детекция PELT, BinSeg, CUSUM, residual и TDA; внешние макроагрегаты и JSON-новости.

## Установка

Python 3.11 рекомендуется; текущая проверка выполнена на Python 3.12. CPU достаточен. Первый запуск Chronos требует доступа к Hugging Face для фиксированного checkpoint; последующие используют локальный кэш.

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py --config configs/config.yaml --all
python -m pytest -q
```

Сырые файлы должны лежать в `datasets/` под именами из YAML. Данные и веса не включаются в Git. Исходный конкурсный `submission.csv` или сохранённый `reports/artifacts/submission_roster.csv` определяет сетку поставки. Без roster runner не выдумывает состав конкурсной сетки.

## Протокол

- Источник таргета: январь 2023 – декабрь 2024. Warm-up — один месяц; неопределённые длинные лаги остаются NaN. Imputer обучается только внутри train.
- `origin=t` означает начало месяца. Признаки содержат сведения до t; direct-цель — y[t+h]. Gap не менее h удаляет ещё не закрытые целевые месяцы из train. Для Chronos контекст заканчивается t−1, поэтому используется h+1 точек пути.
- h=1/3/6: отдельные purged expanding-window direct-панели. h=12: при отсутствии direct-history используется отдельно обозначенная recursive-ветвь CatBoost. Она добавляет только собственные прогнозы; Prophet и Chronos также не используют будущие факты.
- Рекурсивный h=12 CatBoost использует лаги, rolling и календарь. Различные origin и стратегии ограничивают сравнение качества между горизонтами.
- Новости дедуплицируются, агрегируются по публикации и лагируются на месяц. Базовый прогон измеряет log1p(article_count) и standardized volume-shock относительно прошлого окна. Sentiment отключён: прошлый кэш не содержал измерений RuBERT.
- News-ablation для h=1 обучает две отдельные CatBoost-модели с одинаковыми folds и параметрами: с news и без news, сохраняя остальные признаки. Отрицательная дельта считается ухудшением. Рекурсивный h=12 исключён из ablation.
- TDA не входит в прогнозные признаки: текущая топология могла включать ещё не опубликованный таргет. TDA используется в детекции после доступности факта.

## Детекция и интерпретация

Причинные детекторы работают на префиксах; дата обнаружения отделена от оценённой точки изменения. CPD использует h=1 OOF, чтобы разные горизонты не дублировали один целевой месяц. Общероссийский ряд дополняет короткий OOF-префикс.

Каталог содержит шесть событий 2022–2024. Два события 2022 года вне имеющейся истории показываются как out-of-range. Сопоставление остальных событий взаимно однозначное, допуск ±31 день. Каталог — proxy-разметка: решение ЦБ не доказывает локальный структурный сдвиг. Ретроспективные PELT/BinSeg оцениваются отдельно; их даты нельзя выдавать за онлайн-алерты.

Казань — крупный городской потребительский рынок, Норильск — промышленный профиль, Суздаль — туристический район. Отчёт показывает реальные изменения расходов, OOF-ошибки и новости. Сезонность и финансовые условия — гипотезы; приписать изменение конкретной новости по этим данным нельзя.

Алерт инициирует проверку спроса и ошибок прогноза человеком. Стоимость false positive и false negative задаёт владелец процесса; модель не обосновывает автоматические решения по клиентам.

## Финальный submission

Отдельный Prophet обучается для каждого МО на наблюдениях до `2024-07-01` и выдаёт июль–декабрь из одного origin. CatBoost обучается до того же origin и прогнозирует рекурсивно как сравниваемый кандидат; его внешние признаки заморожены. Будущие расходы не используются. Поставка: 2 094 МО × 6 месяцев = 12 564 строк. Корневой и reports CSV записываются идентично после проверки схемы, ключей, количества, конечности и положительности.

Prophet выбран для поставки по наименьшей pooled h=1 MAE и меньшей h=6 MAE в измеренном OOF. CatBoost хранится как сравниваемый кандидат. Устойчивость выбора требует проверки на дополнительных origin.

## Ограничения

49 коллизий названий разрешаются через source/slot; это surrogate, а не ОКТМО. Состав ID меняется между месяцами. Подтверждённого официального crosswalk нет. Rosstat-загрузчик поддерживает XLS/XLSX/CSV, но загрузчик и target-прокси не означают использование реального демографического источника с релизными датами.

Для доказанной оценки 3/3 нужны официальный crosswalk, дополнительная историческая выборка, подтверждённые внешние винтажи и независимая разметка сдвигов. Эти сведения нельзя восстановить из текущего архива без предположений.
