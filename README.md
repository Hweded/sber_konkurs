# СберИндекс: Прогнозирование расходов МО и детекция макрошоков

Проект представляет собой масштабируемый сквозной (E2E) пайплайн для прогнозирования потребительских расходов муниципальных образований РФ на горизонтах 1, 3, 6 и 12 месяцев с адаптивным учётом структурных макроэкономических сдвигов. 

В основу решения заложен **RegimeAware Ensemble**, объединяющий градиентный бустинг (**CatBoost**), байесовское структурное разложение (**Prophet**) и вероятностный трансформер (**Amazon Chronos-Bolt**), дополненный топологическим анализом фазовых траекторий (**TDA**) и детекторами перелома трендов (**CUSUM / PELT**).

## Архитектура ансамблирования (RegimeAware)

Агрегирование прогнозов строится на двухуровневом принципе:
1. **Horizon-Conditioned Base:** на каждом горизонте $h$ веса оптимизированы по Out-of-Fold (OOF) ошибке для минимизации MAE:
   - **$h = 1$ мес.:** CatBoost 56.3% | Prophet 43.7% | Chronos 0.0% (доминирование локального моментума).
   - **$h = 3$ мес.:** CatBoost 77.5% | Chronos 14.1% | Prophet 8.4% (захват среднесрочных нелинейностей трансформером).
   - **$h = 6$ мес.:** CatBoost 85.0% | Prophet 15.0% | Chronos 0.0% (устойчивый среднесрочный тренд).
   - **$h = 12$ мес.:** Prophet 93.0% | CatBoost 7.0% | Chronos 0.0% (доминирование стабильной годовой сезонности).
2. **Decoupled Anomaly Gating:** сигналы детекторов шоков (CUSUM, PELT, TDA-полости) изолированы от прямого признакового пространства и выступают в роли мета-контроллера, демпфируя экстраполяцию старых трендов при структурных изломах.

## Временной контракт (Leak-Free Protocol)

- **Временная причинность:** для прогноза с точки отсечки `origin = t` доступны данные строго с индексом $\tau < t$.
- **Direct-таргет:** обучение моделей на $h=1, 3, 6$ ведётся с защитным окном (gap), исключающим пересечение незакрытых периодов.
- **Foundation-модели:** контекст Chronos-Bolt обрезается на шаге $t-1$, запрашивается $h+1$ квантильный горизонт.
- **Топологические признаки:** персистентные комплексы Вьеториса — Рипса формируются строго в скользящем ретроспективном окне.
- **Разрешение дубликатов:** для 49 коллизий в названиях МО применён детерминированный маппинг `source + ordinal slot` без фиктивной генерации кодов ОКТМО.
