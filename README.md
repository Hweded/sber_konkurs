# СберИндекс: прогноз расходов и структурные изменения

Проект строит прогнозы расходов муниципальных образований на горизонтах 1, 3, 6 и 12 месяцев. В состав пайплайна входят Prophet, CatBoost, Chronos-Bolt, причинная детекция сдвигов и сборка конкурсного сабмита.

## Быстрая проверка

Режим читает сохранённые frozen-origin прогнозы и пересобирает ансамбль на стратифицированной выборке из 150 МО:

```bash
py -3.12 main.py --from-cache --fast
```

Команда записывает только производные файлы в `reports/fast_run/` и не изменяет боевые артефакты. Для запуска нужны базовые кэши прогнозов. Поддерживаются `oof_predictions.parquet` и `test_predictions.parquet` либо раздельные кэши `prophet_preds`, `catboost_preds` и `chronos_preds` с ключами `mo`, `period` и прогнозными колонками.

В текущем рабочем дереве такие кэши отсутствуют, поэтому команда завершается сообщением `Кэш базовых прогнозов не найден`. Это проверка входного контракта, а не успешный прогон ансамбля.

## Прогон из кэша

Полный режим использует тот же код ансамбля для всех МО:

```bash
py -3.12 main.py --from-cache
```

Он пересобирает метрики, отчёты и `submission.csv`. Файлы с базовыми прогнозами должны быть доступны в `reports/artifacts/` или переданы через `--cache-dir`.

Полное переобучение выполняется отдельной командой и требует исходных файлов из `datasets/`:

```bash
py -3.12 main.py --clean-start --all
```

## Результаты

Проверенные OOF-метрики RegimeAware Ensemble и Prophet:

| Горизонт | RegimeAware MAE, ₽ | Prophet MAE, ₽ | Выигрыш RegimeAware |
|---:|---:|---:|---:|
| 1 месяц | 1 914.38 | 2 021.43 | 5.30% |
| 3 месяца | 2 205.28 | 2 265.50 | 2.66% |
| 6 месяцев | 2 905.13 | 2 936.98 | 1.08% |
| 12 месяцев | 4 230.24 | 5 278.02 | 19.85% |

Горизонт 12 месяцев измерен отдельной рекурсивной ветвью CatBoost, поскольку двухлетней истории недостаточно для purged direct-панели. Значения относятся к сохранённым OOF-артефактам; дополнительная проверка на новых origin не выполнялась.

Итоговый сабмит содержит 12 564 строки: 2 094 МО и 6 месяцев. Корневой `submission.csv` и `reports/submission.csv` идентичны. MD5 текущего файла: `e3b2d8abc292640a5be7e1a955c2a3d6`.

## Временной контракт

- `origin=t` — начало месяца; признаки используют только данные до `t`.
- Direct-цель — `y[t+h]`; gap не допускает ещё не закрытые целевые месяцы в train.
- Для Chronos контекст заканчивается на `t-1`, поэтому запрашиваются `h+1` точек.
- Новости агрегируются по месяцу и сдвигаются на один месяц.
- TDA используется только после появления факта и не входит в прогнозные признаки.

## Структура проекта

```text
configs/                 YAML и списки МО для поставки и быстрой проверки
datasets/                исходные выгрузки, не входящие в Git
src/                     загрузка данных, признаки, модели, ансамбль и отчёты
scripts/                 вспомогательные CLI-скрипты
tests/                   модульные и контрактные тесты
reports/artifacts/       метрики, протоколы и сгенерированные таблицы
reports/fast_run/        изолированные результаты режима --fast
main.py                  последовательный запуск пайплайна
requirements.txt         закреплённые зависимости
METHODOLOGY_REPORT.md    подробное описание протокола и ограничений
```

## Установка и тесты

```bash
py -3.12 -m venv .venv
.venv\\Scripts\\activate
py -3.12 -m pip install -r requirements.txt
py -3.12 -m pytest -q
```

Параметры моделей и путей находятся в `configs/config.yaml`. Seed равен 42. Для point-in-time проверки и воспроизводимости не меняйте временной контракт без обновления тестов и отчётов.
